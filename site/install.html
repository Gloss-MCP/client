Install

Gloss is a single, CGO-free Go binary with no runtime dependencies.

From source

Requires Go 1.25+ and make.

git clone https://github.com/gloss-mcp/client.git
cd client
make build
./gloss --version

Put the resulting gloss binary somewhere on your PATH. make build also compiles the Tailwind CSS when it can download the standalone CLI, and otherwise falls back to the committed stylesheet.

Release builds

Planned targets are darwin, linux and windows on arm64 and amd64, via Homebrew (brew install) and a curl install script. This page will be updated with the real commands when the first release is cut.

Where Gloss keeps data

Per-project state lives in .gloss/gloss.db (SQLite) inside the directory you review. It is gitignored by default in this repo; add .gloss/ to your own project's ignore file. Nothing leaves your machine.

Flags

FlagDefaultMeaning
-port4747Port to serve on. 0 picks a free port.
-no-openoffDon't open a browser tab on start.
-authorOS usernameName attributed to threads and comments you write.
-versionPrint the version and exit.

Gloss respects .gitignore in git repositories and a .glossignore file (same syntax, root level only) in any directory.
