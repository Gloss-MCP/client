Install

Gloss is a single, CGO-free Go binary with no runtime dependencies.

Homebrew

macOS and Linux, amd64 and arm64:

brew install gloss-mcp/tap/gloss
gloss -version

Install script

macOS and Linux, amd64 and arm64. It downloads the release archive, checks it against the release's checksums.txt, and installs gloss to ~/.local/bin.

curl -fsSL https://gloss-mcp.github.io/client/install.sh | sh
VariableMeaning
GLOSS_VERSIONInstall this version (for example 0.1.0) instead of the latest release.
GLOSS_INSTALL_DIRInstall here instead of ~/.local/bin.

Pass them to sh, not curl: curl -fsSL https://gloss-mcp.github.io/client/install.sh | GLOSS_VERSION=0.1.0 sh. Release candidates are never picked as the latest version; ask for one with GLOSS_VERSION.

If ~/.local/bin is not on your PATH, the script says so.

Download a release

Every release has archives for Linux, macOS and Windows on amd64 and arm64, named gloss_<version>_<os>_<arch> (.tar.gz, or .zip on Windows), and a checksums.txt.

sha256sum --check --ignore-missing checksums.txt
tar -xzf gloss_0.1.0_linux_amd64.tar.gz
./gloss -version

On Windows, extract the .zip and put gloss.exe somewhere on your PATH. There is no Windows installer yet.

macOS and Gatekeeper

The binaries are not signed or notarised yet. Homebrew and the install script are not affected. If you download the archive in a browser, macOS quarantines the binary and refuses to run it; clear the flag once:

xattr -d com.apple.quarantine gloss

From source

Requires Go 1.25+ and make.

git clone https://github.com/gloss-mcp/client.git
cd client
make build
./gloss -version

Put the resulting gloss binary somewhere on your PATH. make build also compiles the Tailwind CSS when it can download the standalone CLI, and otherwise falls back to the committed stylesheet.

Where Gloss keeps data

Per-project state lives in .gloss/gloss.db (SQLite) inside the directory you review. It is gitignored by default in this repo; add .gloss/ to your own project's ignore file. Nothing leaves your machine.
