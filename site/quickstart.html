Quickstart

Five minutes from install to a full human-reviews, AI-responds loop. You need the binary (brew install gloss-mcp/tap/gloss or the install script) and a directory with some files in it.

1. Start Gloss

cd path/to/your/project
gloss .

Gloss indexes the tracked files and opens http://localhost:4747.

2. Create a session

A session is one review, such as "API design concerns". Use the session switcher in the left nav to create one. Threads belong to a session.

3. Comment on lines

  1. Pick a file in the tree.
  2. Click a line to select it, or click a line and then shift-click another to select a range.
  3. Write a comment and submit. The lines are highlighted in the gutter.

Markdown, JSON and CSV files have view tabs. Selecting in any view anchors to source lines. In a CSV table, click a cell to anchor to it.

4. Connect your AI

Register the MCP endpoint with Claude Code. See the MCP setup guide.

claude mcp add --transport http gloss http://localhost:4747/mcp

5. Let the AI respond

Ask the AI something like:

Use the gloss tools to list the open threads in my latest session,
and reply to each with what you'd change.

Replies appear in the UI with the AI's name. Reload the page to see them: the UI doesn't live-refresh.

6. Edit files freely

If the AI rewrites a reviewed file, Gloss re-anchors your threads. Threads that can't be placed are marked orphaned in yellow, and you can reopen them from the thread list.
