MCP setup

Gloss serves MCP over streamable HTTP at /mcp on the same port as the web UI (default http://localhost:4747/mcp). The server must be running (gloss .) for the AI to reach it. There is no stdio mode.

Claude Code

Either use the CLI:

claude mcp add --transport http gloss http://localhost:4747/mcp

or commit a .mcp.json at your project root:

{
  "mcpServers": {
    "gloss": {
      "type": "http",
      "url": "http://localhost:4747/mcp"
    }
  }
}

If you start Gloss with -port, change the URL to match.

Other clients

Any client that supports streamable HTTP can connect to the same URL. There is no authentication, so the server only listens locally. Don't expose the port.

Attribution

Every write made over MCP is recorded as author_type=ai. The author_agent defaults to the client name sent in the MCP initialize handshake, and any write tool accepts an explicit author_agent to override it.
